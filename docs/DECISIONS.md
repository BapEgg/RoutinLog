# 초기 기술 결정

2026-09-30 기준. 배포 완료를 의미하지 않는다.

| 결정 | 이유 | 바뀔 수 있는 조건 |
|---|---|---|
| Kotlin + Compose Android 앱 | Android 전용 출시와 건강 데이터·기기 권한에 맞는 기본 기술 | 다른 플랫폼 출시를 별도 결정할 때 |
| Kotlin + Spring Boot 서버 | 앱과 언어 통일, Spring의 인증·트랜잭션·운영 기능 사용 | 현재 변경 계획 없음 |
| Spring MVC + JPA | 기록 중심 요청/응답과 관계형 DB에 맞는 익숙한 구조 | 계측 결과 별도 비동기 처리 구조가 필요할 때 |
| 서버 한 개, 기능별 패키지 | 초기 배포·문제 추적·트랜잭션을 단순하게 유지 | 팀·트래픽·장애 격리 요구가 커질 때 |
| PostgreSQL + Flyway | 기록의 관계·버전·중복 제약과 DB 변경 이력 | 현재 변경 계획 없음 |
| 온라인 전용 기록 | 사용자가 확정한 제품 범위 | 오프라인 지원을 별도 결정할 때 |
| Google만 로그인 | 초기 계정 흐름을 단순하게 유지 | 추가 로그인 제공자 필요 시 |
| 정식 계정 API는 인증 구현 전 차단 | 뼈대 단계의 임시 인증이 실제 데이터 접근으로 이어지는 것을 방지 | 실제 Google 검증·세션·소유권 검사 완료 시 |
| Android와 서버 독립 Gradle 프로젝트 | Android SDK 없이 서버 테스트가 가능하고 도구 버전을 독립적으로 갱신 | 실제 공유 코드가 충분히 커질 때 |
| 공통 계산 모듈은 당장 만들지 않음 | 최종 계산은 서버에서 검증하고 앱은 표시·입력에 집중 | 앱에서 반드시 같은 순수 계산이 필요할 때 |
| 클라우드·AI·OCR 자격증명 미포함 | 공급자·비용·개인정보 조건을 실제 연결 시 확정 | 계정과 배포 환경 준비 후 |

앱 패키지명 `com.bapegg.routinlog`는 개발 단계 식별자다. Google Play 최초 등록 및 Google OAuth 클라이언트 생성 전에 소유자가 최종 확정한다. 저장소 이름은 전달받은 `BapEgg/RoutinLog`를 유지한다.
